# app-shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shared Swift package (`app-shell`) giving LaunchApp, Padlet and ZenTask one updater, one About/What's New and one Settings shell, plus a hub rule that keeps every app consistent.

**Architecture:** One SwiftPM package with four library targets (`AppShellCore`, `UpdaterKit`, `AboutKit`, `SettingsKit`), consumed by each app as a git submodule at `Vendor/app-shell` through a local-path dependency. Per-app differences enter as values (`AppInfo`, `AssetMatcher`, `UpdateSettingsStore`, `SettingsShellStyle`), never as switches on app identity.

**Tech Stack:** Swift 6.4 toolchain, SwiftPM (tools 5.9 manifest), SwiftUI + AppKit, Security.framework, XCTest; xcodegen for ZenTask.

**Spec:** `docs/superpowers/specs/2026-11-14-app-shell-design.md` (in the app-shell repo)

## Global Constraints

- Platform floor `.macOS(.v13)`; no `@Observable`; macOS 14+/26 APIs only behind `if #available`.
- Package compiles in Swift 6 language mode with complete concurrency checking; manifest `swift-tools-version:5.9` so Padlet (5.9) can depend on it.
- Author: name `Ha Phung Quang Vu`; website `https://vuhpquang.com`; GitHub `https://github.com/vuhpquang`; LinkedIn `https://www.linkedin.com/in/vuhpquang/`.
- Copyright: `© YEAR Ha Phung Quang Vu`, or `© FIRST–YEAR Ha Phung Quang Vu` (en dash) when first year < current year.
- Update feed: `https://api.github.com/repos/{repo}/releases/latest`, tags `vX.Y.Z`.
- Persisted keys are never renamed: Padlet `Preferences.general.autoCheckUpdates/autoInstallUpdates`; LaunchApp `Preferences.settings.autoCheckUpdates/autoInstallUpdates`; ZenTask UserDefaults `updates.autoCheck`. New keys: `appShell.updates.autoCheck`, `appShell.updates.autoInstall`, `appShell.lastSeenVersion`.
- Assets: Padlet `Padlet.dmg`, LaunchApp `LaunchApp.dmg`, ZenTask `ZenTask-X.Y.Z.zip` (ignore `.apk`).
- Verification never weaker than today: same bundle id + `codesign --verify --deep --strict` + own designated requirement when this copy has certificates.
- Scheduling: first auto check 10 s after start, then every 6 h, only while auto-check is on; a background check never replaces a visible `available` or `failed` state.
- Copy: sentence case, no trailing period on labels, errors say what to do next.
- Commits: personal email, conventional, Claude co-author line; app-shell repo branch `main`.

## Review Focus

1. Release with no matching asset (ZenTask release with only APKs, or a DMG missing) → state `upToDate`, never a crash or `available` with nothing to install. Test in Task 2.
2. Tags like `v1.4`, `1.4.2`, `v1.5.0-beta` vs current `1.4.2` → numeric compare, suffix ignored, missing parts = 0. Test in Task 2.
3. GitHub rate-limit / non-200 / malformed JSON → `failed("Couldn't reach GitHub. Check your connection and try again")`, and a background check leaves an existing `available` untouched. Test in Task 3.
4. App not in a writable folder (running from DMG or a read-only location) → `failed` with "Move <App> to Applications and try again" before any download. Test in Task 3.
5. First launch with no `lastSeenVersion` → records silently, no What's New; second launch on a newer version → offered once, then not again. Test in Task 5.

### Task 3: Updater state machine

**Files:** `Transport.swift`, `UpdateSettingsStore.swift`, `Updater.swift`, `Installer.swift`, tests `UpdaterTests.swift`.

**Interfaces — Produces:**
- `public protocol UpdateTransport: Sendable { func latestRelease(repo: String, userAgent: String) async throws -> Release; func download(_ url: URL) async throws -> URL }` + `URLSessionTransport`.
- `@MainActor public protocol UpdateSettingsStore: AnyObject { var autoCheck: Bool { get set }; var autoInstall: Bool { get set }; var changes: AnyPublisher<Void, Never> { get } }` + `public final class UserDefaultsUpdateSettings: UpdateSettingsStore, ObservableObject { init(defaults: UserDefaults = .standard, autoCheckKey: String = "appShell.updates.autoCheck", autoInstallKey: String? = "appShell.updates.autoInstall", autoCheckDefault: Bool = true) }` (nil autoInstallKey → always false, not settable).
- `@MainActor public final class Updater: ObservableObject` with `enum State: Equatable { idle, checking, upToDate, available(version: String), downloading, installing, failed(String) }`, `@Published state, lastChecked: Date?, releaseNotes: String`, `init(app: AppInfo, matcher: AssetMatcher, settings: UpdateSettingsStore, transport: UpdateTransport = URLSessionTransport(), installer: Installing = Installer())`, `var currentVersion: String` (DEBUG env `APPSHELL_PRETEND_VERSION` override), `func startAutomaticChecks()`, `func check(userInitiated: Bool)` (fire-and-forget) and `func checkNow(userInitiated: Bool) async`, `func install()`, `var onWillRelaunch: (@MainActor () -> Void)?`, `var relaunchArguments: [String]`, `func dryRun() async -> String`.
- `public protocol Installing: Sendable { func preflight(target: URL, appName: String) throws; func stage(_ file: URL, kind: AssetMatcher.Kind, bundleId: String?) throws -> URL; @MainActor func relaunch(replacing target: URL, with staged: URL, arguments: [String]) throws }`; `Installer` = today's Padlet code (hdiutil / ditto -x -k, codesign, `satisfiesOwnSigner`, detached `/bin/sh` swap script with `xattr -dr com.apple.quarantine`, `open "$1" --args …`).
